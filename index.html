A smart wallet that guards itself. It responds to a spoken command to arm and disarm, and sounds an audible alarm through an onboard speaker when it is opened without authorisation.

محفظة ذكية تحرس نفسها. تستجيب لأمر صوتي منطوق للتفعيل وإلغاء التفعيل، وتُطلق إنذارًا مسموعًا عبر سمّاعة مدمجة عند فتحها دون إذن.

Built on an STM32 Blue Pill with firmware written in bare-metal C, driving a voice input module, Bluetooth, and speaker output. The enclosure was modelled and 3D printed to fit the board, speaker and battery.

بُنيت على لوحة STM32 Blue Pill ببرمجية مكتوبة بلغة C مباشرةً على العتاد، تُشغّل وحدة إدخال صوتي والبلوتوث ومخرج السمّاعة. صُمّمت الحاوية ثم طُبعت بالطباعة ثلاثية الأبعاد لتناسب اللوحة والسمّاعة والبطارية.

Text editor built from scratchمحرّر نصوص مبني من الصفر

Languageاللغة
JavaJava
Contextالسياق
University projectمشروع جامعي

A full text editor written from the ground up in Java, without using an existing editor component — file handling, the text buffer and the interface were all built directly. It supports opening and saving files, find and replace, undo and redo, cut, copy and paste, line numbers, syntax highlighting, adjustable font size, word count, and multiple open tabs.

محرّر نصوص كامل مكتوب من الصفر بلغة Java، دون استخدام مكوّن محرّر جاهز — فالتعامل مع الملفات ومخزن النص والواجهة بُنيت جميعها مباشرةً. يدعم فتح الملفات وحفظها، والبحث والاستبدال، والتراجع والإعادة، والقص والنسخ واللصق، وأرقام الأسطر، وتلوين الصياغة، وضبط حجم الخط، وعدّ الكلمات، وفتح عدة تبويبات.
